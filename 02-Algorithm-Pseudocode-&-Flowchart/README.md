## 🧩 **1. What is an Algorithm?**

* An **algorithm** is just a step-by-step set of instructions to solve a problem.
* Don’t think of it as something complex—it’s just like giving someone directions.

👉 **Example 1: Algorithm for making tea**

1. Boil water.
2. Add tea leaves.
3. Add milk and sugar.
4. Stir and pour into a cup.
5. Enjoy your tea. ☕

👉 **Example 2: Algorithm for finding the largest of two numbers (a, b):**

1. Start
2. Compare a and b
3. If a > b → Print a is largest
4. Otherwise → Print b is largest
5. End

📌 Notice how simple this is—we’re just writing steps in plain language!

---

## ✍️ **2. What is Pseudocode?**

* **Pseudocode** is writing down the steps of an algorithm in a structured way (but not in real programming language).
* It’s a bridge between **thinking** and **coding**.

👉 Example: Largest of two numbers (a, b) in pseudocode:

```
START
   READ a, b
   IF a > b THEN
       PRINT "a is largest"
   ELSE
       PRINT "b is largest"
   ENDIF
END
```

📌 See? It’s not real code, but it looks structured and closer to coding.

---

## 🔄 **3. What is a Flowchart?**

* A **Flowchart** is a **diagram** that shows the steps of a problem visually.
* Flowcharts use **symbols**:

  * 🔵 **Oval** → Start / End
  * ⬛ **Rectangle** → Process / Action
  * 🔶 **Diamond** → Decision (Yes/No)
  * ➡️ **Arrow** → Flow direction

👉 **Example Flowchart: ATM Cash Withdrawal**

1. Start
2. Insert Card
3. Enter PIN
4. Correct PIN? (Decision)

   * Yes → Withdraw cash
   * No → Show error
5. End

📌 Students can imagine this flow in real life—it’s exactly how ATMs work.

## 🔗 **4. Connecting Everything Together**

When solving a problem as a programmer, follow these steps:

1. Write the **Algorithm** (steps in simple words).
2. Convert it into **Pseudocode** (structured format).
3. Draw a **Flowchart** (visual diagram).
4. Finally, implement it into **Code** in a programming language.

👉 Example (Check even or odd number):

* **Algorithm:**

  1. Start
  2. Input number
  3. If number % 2 == 0 → Print Even
  4. Else → Print Odd
  5. End

* **Pseudocode:**

  ```
  START
     READ number
     IF number % 2 == 0 THEN
        PRINT "Even"
     ELSE
        PRINT "Odd"
     ENDIF
  END
  ```

* **Flowchart:**

  * Start → Input number → Decision (Is number divisible by 2?) → Yes → Even → End
  * No → Odd → End
